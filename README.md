# SemanaTec

Repositorio creado en semana tec primer semestre bloque 2, El arte de la programación. By Andres Godina, Cesar Badillo, Juan Pablo Cortes

Busca una palabra en los archivos `.txt` de una carpeta y sus subcarpetas.

```bash
bash buscar_home.sh cesar textos
```

El primer dato es la palabra y el segundo es la carpeta. El script busca en
toda la ruta que le indiques (incluyendo subcarpetas), avisa si faltan datos o
si la carpeta no existe, y acepta rutas con espacios.
