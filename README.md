# SemanaTec

Repositorio creado en semana tec primer semestre bloque 2, El arte de la programación. By Andres Godina, Cesar Badillo, Juan Pablo Cortes

Busca una palabra en los archivos `.txt` de una carpeta.

```bash
bash buscar_home.sh home textos
```

El primer dato es la palabra y el segundo es la carpeta.
